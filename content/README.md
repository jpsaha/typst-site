# Content

Human-authored source material.

This directory contains the mathematical and educational content of the project.

## Contents

- `courses/` — course-level material
- `lectures/` — lecture material
- `mopss/` — MOPSS material and related problem solutions
- `olympiad/` — olympiad preparation and problem material

## Principle

This is the primary authoring layer of the project.

Files here should contain **content**, not build-system logic or generated output.
