# Figures

Source figures and diagrams.

This directory contains figureThis directhe mathematical content, including diagrams,
illustrations, plots, and other visual source material.

## Contents

- `common/` — figures shared across multiple documents
- `lectures/` — lecture-specific figures
- `olympiad/` — olympiad-specific figures

## Principle

This directory contains **source visual material**.

Generated or publication-specific copies should not be stored here; those belong in
the appropriate output directory under `dist/`.
